Five ideas carry the kit. A library reports spans and draws nothing. A
command picks the display. Work rolls up the tree. Text from elsewhere is
escaped in one place. And each choice that depends on a program stays in
the program. The last two pages, the architecture and the event log, come
from the repository as they are.
